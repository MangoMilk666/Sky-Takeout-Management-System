优惠券模块接口文档 v1

覆盖：商家发布+Redis预热、用户端Lua抢券+异步落库、下单使用与支付失败回退（幂等）。

通用约定

  • 所有写接口建议携带 requestId（客户端生成 UUID）用于幂等。
  • 错误统一返回：{ ok:false, code:"...", message:"..." }。

商家端接口（Admin）

MethodPath说明
POST/api/admin/coupon-templates创建优惠券模板（草稿）
PUT/api/admin/coupon-templates/{id}编辑模板
POST/api/admin/coupon-templates/{id}/publish发布模板并触发 Redis 预热
POST/api/admin/coupon-templates/{id}/offline下线模板（用户端不可再领）
GET/api/admin/coupon-templates/{id}/stats统计：发放/核销/回退/异常

发布接口示例

POST /api/admin/coupon-templates/CT1001/publish

Response
{
  "ok": true,
  "templateId": "CT1001",
  "warmedUp": true
}

用户端接口（User）

MethodPath说明
GET/api/coupons/available可领取优惠券模板列表
POST/api/coupons/claimLua 抢券：原子校验+扣减+入队异步落库
GET/api/coupons/mine我的优惠券列表（AVAILABLE/LOCKED/USED/EXPIRED）

抢券接口（Lua）

POST /api/coupons/claim
{
  "templateId": "CT1001",
  "requestId": "0f2b8c1a-7d2e-4a8a-9e6e-..."
}

Response
{
  "ok": true,
  "code": "OK"
}

失败示例
{ "ok": false, "code": "OUT_OF_STOCK", "message": "已抢光" }

下单/支付接口（Checkout）

MethodPath说明
POST/api/checkout/coupons/recommend按订单金额/范围计算可用券与推荐券
POST/api/checkout/coupons/lock锁券：AVAILABLE -> LOCKED（防并发重复使用）
POST/api/checkout/coupons/confirm-used核销：LOCKED -> USED（支付成功回调/业务确认）
POST/api/checkout/coupons/release-lock回退：LOCKED -> AVAILABLE（支付失败/取消/超时）

锁券接口示例

POST /api/checkout/coupons/lock
{
  "orderId": "O202604120001",
  "userCouponId": "UC9001",
  "requestId": "a3d4..."
}

Response
{ "ok": true, "status": "LOCKED" }

回退接口示例

POST /api/checkout/coupons/release-lock
{
  "orderId": "O202604120001",
  "userCouponId": "UC9001",
  "requestId": "a3d4...",
  "reason": "PAY_FAILED"
}

Response
{ "ok": true, "status": "AVAILABLE" }
