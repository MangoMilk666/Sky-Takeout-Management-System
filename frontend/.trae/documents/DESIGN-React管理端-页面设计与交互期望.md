# React 管理端页面设计与交互期望（对齐原 Vue）

## 全局设计规范（Desktop-first）
- Layout：左侧固定侧边栏 + 右侧内容区；顶部栏固定；内容区滚动。
- 断点：
  - ≥1200px：侧边栏默认展开（展示 icon + 文案）。
  - 768–1199px：侧边栏可折叠，默认展开；折叠后仅 icon。
  - <768px：允许折叠为抽屉（可选），但本次以桌面优先不强制。
- Meta：
  - title：`IntelliDining - {页面名}`（与现有 usePageTitle 一致）。
  - description/og：管理端内部系统，可不配置 SEO 重点；保留默认即可。
- Global Styles（与 legacy-vue 主题对齐）：
  - 主色：沿用现有 legacy-vue 样式（按钮 primary、链接蓝色）。
  - 字体：系统字体栈；表格/表单字号 12–14。
  - 反馈：统一使用 Toast（message.success/error）；确认使用 Modal.confirm / 对齐 Element MessageBox 风格。

## 1) 登录页（LoginPage）
- Page Structure：左右分栏卡片：左侧插画图，右侧登录表单。
- Sections & Components：
  - Logo 区：上方居中显示 logo。
  - 表单区：账号输入、密码输入、登录按钮。
- 交互期望（问题#1）：
  - 初始账号/密码为空（不预填）。
  - 账号必填；密码必填且长度规则与原 Vue 一致。
  - 回车触发表单提交。
  - 登录中按钮禁用并显示“登录中...”。
  - 登录失败：
    - 表单项展示错误态（红框/错误文案）；
    - 同时弹出 Toast（与原 Vue 提示一致）。

## 2) 主布局（RootLayout：侧边栏+顶部栏）
### 2.1 侧边栏
- Layout：固定宽度侧边栏，顶部 logo，下面为菜单列表。
- 交互：
  - 点击汉堡按钮折叠/展开。
  - 当前路由高亮（与 Vue 一致：父路径命中子路由也高亮）。

### 2.2 顶部栏：营业状态 + 用户菜单
- 元素：
  - 左侧：折叠按钮 + “营业中/打烊中”状态标签。
  - 右侧：营业状态设置入口 + 用户名下拉。

- 交互期望（问题#2 营业状态设置）：
  - 页面加载：调用原 Vue 使用的“查询营业状态”接口，渲染状态标签。
  - 点击“营业状态设置”：弹出确认（或二选一）对话框：切换到“营业中/打烊中”。
  - 确认后：调用原 Vue 使用的“切换营业状态”接口；成功后刷新状态并 Toast。
  - 失败：Toast 提示失败原因；状态不变化。

- 交互期望（问题#3 用户菜单/修改密码）：
  - 点击用户名：下拉菜单（修改密码 / 退出登录）。
  - 修改密码：弹窗包含旧密码、新密码、确认密码；校验与原 Vue 一致；成功后提示并按原版策略要求重新登录或关闭。
  - 退出登录：清理本地 token/cookie，跳转登录页。

## 3) 工作台（DashboardPage）
- Page Structure：卡片式仪表盘，多行栅格（Row/Col）。
- 模块对齐（问题#4）：
  1. 今日数据卡：营业额、有效订单、完成率、客单价、新增用户。
  2. 订单概览卡：待接单/待派送/派送中/已完成/已取消/全部（与原 Vue 指标一致）。
  3. 菜品/套餐总览：启售/停售数量。
  4. 待处理订单列表（或等效模块）：展示待接单/待派送订单关键信息（订单号、时间、金额、收货信息），提供“查看/接单/拒单/取消/派送”等快捷操作（按钮与原 Vue 一致）。

- 跳转交互：
  - 点击订单概览中的任一指标：跳转订单管理页并自动带入对应状态筛选（通过 query 参数 status）。
  - 点击“查看”：打开订单详情（同订单页详情组件）。

## 4) 订单管理（OrderPage）
### 4.1 列表区
- Structure：顶部 Tabs（全部/待接单/待派送/派送中/已完成/已取消）+ 筛选条 + 表格。
- 交互：
  - 切换 Tab：同步 URL query `status`；清空筛选条件；列表回到第 1 页。
  - 查询：带筛选条件请求；空结果显示“未搜索到相关订单”。

### 4.2 订单详情（问题#5）
- 展示方式：Modal 或 Drawer（二选一，保持与原 Vue 一致）。
- 内容结构（不允许 raw JSON）：
  - 基本信息：订单号、状态、下单时间、支付方式/备注（若有）、金额。
  - 收货信息：收货人、手机号、地址。
  - 菜品明细：表格（菜品名、规格/口味（若有）、数量、单价、小计）。
  - 状态相关信息：取消原因/拒单原因（若有）。
- 操作按钮：
  - 待接单：接单 / 拒单 / 取消。
  - 待派送：派送。
  - 派送中：完成。
  - 已完成/已取消：仅查看。
- URL 行为：
  - 打开详情时写入 `orderId`；关闭详情时移除 `orderId`。
  - 支持直接访问带 `orderId` 的 URL 自动打开详情。

### 4.3 取消/拒单弹窗
- 结构：原因下拉（含“自定义原因”）+ 备注输入。
- 校验：必须选择原因；自定义原因必须填写备注。

## 5) 员工管理（EmployeePage）
- Page Structure：查询条 + 表格 + 分页。
- 交互期望（对齐原 Vue 反馈样式）：
  - 查询：回车或点击“查询”触发；清空输入立即恢复全量列表。
  - 启用/禁用：使用统一确认弹窗与 Toast（不使用浏览器 alert/confirm）；成功后刷新列表；失败提示明确原因。
  - 禁止操作 admin 账号：按钮置灰且 hover 有解释（可选）。
